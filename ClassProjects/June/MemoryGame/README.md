# Memory Game Using APIs

This web game lets you test your memory with different types of themes.

## How to Run
1. Download the project files
2. Open `index.html` in your browser
3. No installs needed!

## How to Play
1. Choose a theme — or let the game choose randomly for you
2. Flip two cards at a time
3. If they match they stay face up, if not they flip back
4. Match all 8 pairs to win!

## Themes
-  Harry Potter characters
-  Dogs
-  Countries from all over the world
-  Surprise Me — picks a random theme for you

## APIs Used
- Harry Potter — https://hp-api.onrender.com
- Dogs — https://dog.ceo/dog-api
- Countries — https://restcountries.com

## Files
- `index.html` — the page structure
- `styles.css` — the styling
- `script.js` — the game logic
